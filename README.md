# Dynamic Product System (MERN)

## 📌 Overview
This project is a dynamic product management system where categories define their own attributes and products are created dynamically based on those categories.

---

## 🚀 Features

- Dynamic Category Creation
- Dynamic Product Attributes
- Product Details Page
- Backend-driven Filters
- No Hardcoding

---

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB

## Setup Instructions

### Backend

cd backend  
npm install  
npm start  

### Frontend

cd frontend  
npm install  
npm start  

---

## Note

If frontend is not accessible, please ensure backend is running on port 5000 and frontend on port 3000.
